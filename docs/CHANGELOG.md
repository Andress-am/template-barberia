# Historial de versiones — Plantilla Barbería

## v1.0.0

Primera versión estable de la plantilla.

- Arquitectura completa: core / features / verticals / site
- Sistema de diseño (colores, tipografía, espaciados) en tokens.css
- Configuración del cliente validada con Zod (business, theme, seo, features)
- 13 secciones: Navbar, Hero, Servicios, Galería, Sobre nosotros, Equipo,
  Reservación (flujo de 6 pasos), Testimonios, Promoción, Ubicación, FAQ,
  CTA final y Footer
- Diseño responsive verificado en celular, tablet y escritorio
- Imágenes: aún con placeholders, pendientes de fotos reales
